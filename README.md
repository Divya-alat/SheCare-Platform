## 🌟 About SHEcare

**SheCare** is a comprehensive women's health and safety platform that combines AI, real-time tracking, and smart features to empower women at every stage of life. From tracking menstrual cycles to detecting PCOS risk, providing pregnancy guidance, and offering an emergency SOS system — SHEcare is a one-stop solution for every woman's needs.

> 💡 *Built with empathy, powered by technology.*

---

## ✨ Features

| Feature | Description |
|---------|-------------|
| 🩸 **Period Tracker** | Track menstrual cycles, predict next period, log symptoms |
| 🔬 **PCOS Detection** | AI-based PCOS risk assessment using health inputs |
| 🤰 **Pregnancy Guide** | Week-by-week pregnancy tracking and health tips |
| 🆘 **Safety SOS** | Emergency alert system with location sharing |
| 🧘 **Lifestyle & Stress** | Stress management tips, lifestyle recommendations |
| 🤖 **AI Chatbot** | 24/7 health assistant for women's queries |

## ⚙️ Run Locally

```bash
# Clone the repository
git clone https://github.com/Divya-alat/shecare-platform.git

# Go into the project
cd shecare-platform

# Install dependencies
npm install

# Create .env.local file and add:
# MONGODB_URI=your_mongodb_connection_string

# Run the development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser 🎉
